# First PR Practice

A tiny playground repo for practicing the GitHub pull request workflow.

## What is this?

This repo exists so you can open a small, low-stakes PR and see the whole flow end to end:
branch, commit, push, and merge.

## Files

- `greet.py` — a small script that prints a greeting.

## Usage

```bash
python greet.py
```

You should receive a friendly greeting in your terminal.
